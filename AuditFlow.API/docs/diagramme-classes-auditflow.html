Relations clefs

  • AuditorAccount herite de User.

Services, contextes et hooks

Service

  • signUp()

  • getUser()
  • signOut()
Service

ProfileStorageService

  • createDefaultProfile()
  • loadStoredProfile()
  • saveStoredProfile()
  • mergeUserWithStoredProfile()
Contexte

UserContextValue

  • user
  • error
  • isLoading
  • checkSession()
Contexte

NotificationsContextValue

  • notifications[]
  • addNotification()
  • clearNotifications()
Contexte

AppLanguageContextValue

  • language
  • setLanguage()
  • usage actuel : francais fixe
Hook

UseWorkspace

  • workspace
  • isReady
  • ecoute WORKSPACE_UPDATED_EVENT

Relations fonctionnelles

  • AuthClient s'appuie sur AuditorAccount pour valider les acces ONCF.
  • AuthClient reconstruit l'utilisateur via createStoredUser() puis mergeUserWithStoredProfile().
  • UserProvider depend de AuthClient pour charger la session et exposer UserContextValue.
  • NotificationsProvider gere un historique local d'AppNotification.
  • UseWorkspace recharge WorkspaceState a chaque evenement de mise a jour.
  • ProfileStorageService diffuse PROFILE_UPDATED_EVENT pour resynchroniser l'avatar et le profil.
  • AppLanguageProvider conserve une interface de langue mais l'application est verrouillee sur fr.
Bloc 4

Pages et navigation

Navigation

Paths

  • auth/sign-in, sign-up, reset-password
  • dashboard overview
  • study-phase, follow-up, rapport
  • missions, archives, support
  • notifications, account, settings
Navigation

NavItemConfig

  • key, title, icon, href
  • items[]
  • matcher
Page

RootPage / SignInForm

  • RootPage redirige vers sign-in
  • SignInForm appelle AuthClient
  • ouvre un panneau de selection des missions
  • consomme UseWorkspace et Paths
Page

DashboardOverviewPage

  • consomme UseWorkspace
  • affiche les KPI globaux
  • tableau verification des missions
  • plein ecran du registre
Page

NewMissionPage

  • consomme missionTemplates
  • genere un AuditMission
  • sauvegarde via saveWorkspaceMission()
  • notifie la creation
Page

MissionsPage / MissionDetailsPage

  • lisent workspace.missions
  • ouvrent une mission par id
  • suppriment via deleteWorkspaceMission()
  • emet tent des notifications
Page

ArchivesPage

  • lit workspace.archives
  • ouvre les details mission
  • adapte le texte via AppLanguageContext
Page

StudyPhasePage

  • gere les 5 onglets et leur pagination
  • genere, modifie, valide et sauvegarde
  • persist StudyState
Page

OrientationReportPage

  • lit et edite OrientationReportData
  • calcule la progression
  • persist OrientationPageState
Page

FollowUpPage

  • utilise workspace.followUpActions
  • ajoute, importe, deplace et supprime
  • met a jour le diagramme dynamique
  • persiste les actions de suivi
Page

Pages transverses

  • NotificationsPage
  • SupportPage
  • AccountPage
  • SettingsPage

Relations clefs

  • Paths alimente la navigation laterale et les liens de pages.
  • SignInForm depend de AuthClient et du registre partage des missions.
  • DashboardOverviewPage, MissionsPage, MissionDetailsPage et ArchivesPage lisent AuditMission via WorkspaceState.
  • NewMissionPage ecrit dans WorkspaceState via saveWorkspaceMission().
  • StudyPhasePage ecrit dans studyPhaseState.
  • OrientationReportPage ecrit dans orientationReportState.
  • FollowUpPage lit et ecrit WorkspaceFollowUpAction[] en temps reel.
