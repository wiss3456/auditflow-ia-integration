# Deploiement

Ce repository ne definit pas un deploiement global unique.

Chaque projet doit etre deployee selon sa propre stack et sa propre documentation.

## Regle

- deployer `AuditFlow.API` selon ses besoins frontend/backend
- deployer les services Python separement
- ne pas supposer un pipeline unique pour tous les projets

## Consequence

Le present depot sert a :

- centraliser les sources
- conserver les documents PDF
- organiser les references techniques

Il ne remplace pas la documentation de deploiement de chaque projet.
