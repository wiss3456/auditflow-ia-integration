# PostgreSQL

La partie `PostgreSQL` concerne principalement le projet :

- `AuditFlow.API/`

Si vous travaillez sur cette partie, utilisez les fichiers de configuration et les migrations contenus dans ce projet.

## Point important

Les fichiers sensibles doivent rester hors versionning.

Exemples :

- `AuditFlow.API/backend/AuditFlow.Api/appsettings.json`
- `AuditFlow.API/backend/AuditFlow.Api/appsettings.Development.json`

Utiliser les fichiers d'exemple fournis dans le projet comme base locale.
